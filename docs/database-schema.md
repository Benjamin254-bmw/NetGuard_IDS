# Database schema reference

Generated by `make docs-schema` from `netguard_common.models` and `netguard_common.grants`. Do not edit by hand. Migrations in `migrations/` are the deployed source of truth; `make migrate-check` fails if they drift from the models.

Conventions: all timestamps are `timestamptz` (UTC); addresses are `inet`/`macaddr`; enumerations are text with a named CHECK; the monitor and API roles hold only the privileges listed per table.

## `ingest_batches`

Ledger of batches the monitor has applied. A batch id is inserted in the same transaction as its data, so replaying a spilled batch (or re-applying after a crash) can never double count.
